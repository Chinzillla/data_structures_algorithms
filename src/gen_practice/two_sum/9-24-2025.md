## Phase 1: Set up

### Understanding the Question:

We are given two pieces of data
- Nums = array[int]
- Target = int

- Every array has exactly two unique elements that add up to target and there only exists exactly one solution for every num and target input.

- Order of the result does not matter


### Constraints:

- Nums.length is between 2 and 104 inclusive
- Each element within nums is between -10^9 and 10^9 inclusive
- The target is between -10^9 and 10^9 Inclusive

### Edge Cases:

- Handling two element array input
- Handle incorrect inputs and no solution inputs with error handler

### Writing Test Cases:

- Num = [1,2,3,7], target = 8

This is a valid test case because there exists only one pair that sums up to target.

- Num = [-10000, 0, 10001], target = 1

Valid test case, -10000 + 10001 is equal to target.


## Phase 2: Approach

### Possible Approaches:

Brute Force Approach: Traversing through the numbers and checking every combination until we get the two number combinations that add up to target.

Optimized Approach: Spending extra space complexity from constant to linear to cache complements so that we only need to perform one pass on the array.

### Estimated Time Complexity:

Brute Force Approach
- Time complexity: O(n^2)
- Space complexity: O(1)

Optimized Approach
- Time complexity: O(n)
- Space complexity: O(n)

### Best approach:

I think the best approach is the optimized Approach where we can reduce the time complexity from O(n^2) to O(n) at the cost of increasing space complexity from constant to linear.
 
### Skeleton Structure:

1. We can account for the constraints and edge cases at the beginning of program:
- if nums is not within the constraints: raise ValueError("")
- if nums is equal to 2 and nums[0] + nums[1] == target: return [0, 1]
- if nums is equal to 2 and nums[0] + nums[1] != target: raise ValueError("")

2. We will instantiate a new dictionary

3. We will perform a one pass on the array

4. We will check if the complement target - nums[i] exists in the dictionary, if it does we can return the result. If not we want to add the nums[i] to the dictionary as seen.

5. If we find no result then we will raise a ValueError
